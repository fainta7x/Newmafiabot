# Аудит: дата игры и период рейтинга — 2026-10-12

**Источник:** проверка `clubGameAnalyticsService.ts`, `gameStatisticsService.ts`, `playerClubWorldRoutes.ts`, `clubSeasonService.ts`.

- **Подтверждено:** сезонная таблица использовала `games.created_at` раньше, чем дату фактического окончания в протоколе. Другая статистика фильтровала по `protocol.completed_at`. Сохранённая до полуночи и завершённая после полуночи игра могла оказаться в разных сезонах/периодах.
- **Изменено:** сезонный снапшот использует `protocol.completed_at`; в старых протоколах без этой даты остаются прежние запасные даты. Для чтений завершённых клубных игр введён общий `isCompletedClubGamePayload`, без записи в базу.
- **Исправлена подпись:** «Сезоны считаются по календарю» в API мира клуба устарела — источник периодов `rating_periods` типа RATING.
- **Проверка:** `src/tests/completedClubGame.test.ts` — граница сезонов, старые даты, черновики и повреждённая дата. После деплоя нужно проверить реальные игры, пересчёт старых данных намеренно не запускается.

Запись вынесена отдельно, поскольку `docs/AUDIT_LOG.md` параллельно был обновлён в другом PR (#869); его новые строки следует сохранить, а не перетирать.
