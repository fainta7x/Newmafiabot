# Dendi — новый иллюстрированный арт: подготовка ассетов

**PR #891, не мержить без визуального утверждения.** Этот документ описывает не проект нового интерфейса, а фактический результат подготовки *двух новых* сгенерированных изображений: отдельного портрета Денди и листа одежды/аксессуаров.

## Входные изображения и воспроизводимость

Существуют два новых исходника с прозрачностью:
- портрет 1122×1402 RGBA: длинные русые волосы, голубые глаза, бордовый костюм, руки у бабочки;
- лист 1448×1086 RGBA: 2 пиджака, бабочка, галстук, 2 шляпы, брошь и цепочка.

Это **новый художественный исходник**, не старый JPG из `public/player-avatars`, и не векторный SVG-пилот. В публичный каталог или инвентарь ничего не выпущено.

Добавлен `scripts/prepareDendiPremiumArt.py`. Скрипт принимает оба PNG, валидирует размеры и альфа-канал и делает девять независимых объектов (портрет плюс 8 предметов), включая четыре заранее выровненных RGBA-оверлея 1122×1402 и машинный `manifest.json`.

```sh
python -m pip install Pillow
python scripts/prepareDendiPremiumArt.py \
  --portrait /path/to/dendi-portrait.png \
  --sheet /path/to/dendi-wardrobe-sheet.png \
  --out public/character-editor/premium-assets
```

До добавления оригинальных PNG в репозиторий этот скрипт **не будет автоматически запускаться в CI**. Текстовый GitHub-интерфейс этой сессии не принимает готовые бинарные изображения — не утверждать, что они уже закоммичены. В разговоре есть скачиваемый архив с результатом импорта и автономный HTML. Для дальнейшего переноса PNG в GitHub необходим бинарный upload в папку `public/character-editor/premium-assets` (например через GitHub Work/десктопный git).

## Художественная совместимость — честная матрица

| Компонент | Результат | Ограничение |
| --- | --- | --- |
| Новый портрет Денди | Готов как отдельный прозрачный иллюстрированный исходник | Не является нейтральной базой: пиджак, руки и бабочка нарисованы целиком |
| Бордовая шляпа | Подготовлен PNG и приблизительно размещён на портрете | Требуются худож. посадка и чистка краёв |
| Чёрная шляпа | Подготовлен PNG и приблизительно размещён на портрете | Возможны фрагменты соседних объектов листа по краям |
| Брошь | Подготовлен PNG и оверлей | Масштаб и положение требуют одобрения |
| Цепочка | Подготовлен PNG и оверлей | Масштаб и положение требуют одобрения |
| Бордовый пиджак | Отдельный прозрачный PNG, пригоден для карточки предмета | **Нельзя надевать на этот портрет**: другая поза рукавов и рук, под текущим пиджаком нет нейтрального тела |
| Чёрный пиджак | То же | Та же несовместимость |
| Бабочка, галстук | Отдельные PNG, пригодны для карточек | Старая бабочка уже нарисована на шее портрета; требуется нейтральная воротниковая основа |

**Нельзя** программно заменить только цвет пиджака в цельном портрете и выдавать это за свободно сменяемый предмет. Нельзя считать нейтральное тело готовым, когда под существующей одеждой оно не нарисовано.

## Действующий тест

В автономной HTML-примерке используются реальные PNG, четыре локальных ролевых пресета и отдельные независимые слоты головных уборов и украшений. Пиджаки/галстук отображаются только как исходные образцы с объяснением блокировки. В приложении клуба это пока **не действующий редактор**, кнопки выдачи/покупки отсутствуют. Сохранение локальное и зависит от возможностей браузера.

Проведена локальная проверка ширин 390/1440 px, присутствия четырёх переключателей ролей, отдельных картинок и отсутствия JS-ошибок/горизонтального переполнения. **Проверка в file-origin браузере не подтверждает работу постоянного localStorage** — локальное сохранение может блокироваться политикой конкретного браузера.

## Следующий арт-этап до полноценной примерки одежды

Нужен согласованный набор **одной базовой фигуры Денди в нейтральной рубашке без пиджака и бабочки**, плюс те же две куртки/пиджака в точной той же позе, где руки согласованы с персонажем, и отдельный нейтральный воротник. Все RGBA имеют единый canvas, якорные координаты и порядок наложения: body → shirt → jacket → neckwear → hands → hair front → hat → small accessories. С таким исходником можно безопасно включить оставшиеся слоты уже существующего редактора без переписывания сохранения образов.

Количество вещей и редкости из утверждённой матрицы сезона «Огненная осень» остаются без изменений. Эти технические образцы в сезон автоматически **не попадают**.
