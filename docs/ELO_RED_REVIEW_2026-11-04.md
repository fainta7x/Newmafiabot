# Обсуждение баланса мирного — 4 ноября 2026

Владелец уточнил цель: проверить смысл и цены действий, а не только совпадение сохранённых сумм с расчётчиком. Работа пока только с citizen. Пожелания — смягчить ответственность голосующего по неверному завещанию; автор должен нести большую ответственность; корректно оплачивать каждый чёрный выход попилом; на итоговой картинке явно показывать командную часть за победу/поражение. Остальные роли, цены завещаний/ЛХ и находок чёрных пока не меняются. Это обсуждение/локальная симуляция, не разрешённая новая формула и не production-пересчёт.

## Предложенный для сравнения вариант (не утверждён)

Обычный голос в другого красного: −3, если цель не ушла; −6, если ушла. На критическом круге −6/−12. За один такой голос итог с серией не ниже −12. Самоголосование сохраняет прежнее исключение; шериф не затрагивается. Для отдельного варианта смягчения по завещанию берётся половина нового штрафа без надбавки серии, если все ранее записанные завещания убитых красных, упомянувшие цель, единогласно называют её чёрной (хотя бы одно). Если мнения расходятся — смягчения нет. Это условие и коэффициент требуют согласования. Мотив «послушал завещание» из лога доказать нельзя, видны лишь предшествующие записи и сам голос.

В актуальном коде общего смягчения за чужое обычное неверное завещание НЕТ. Есть удвоенная ошибка автора, назвавшего красного чёрным, если того позже заголосовали. Отдельного штрафа «не проголосовал в чёрного» нет. Узкая модель очевидных чёрных по лжепроверке не заменяет смягчение по обычным завещаниям.

## Примеры последнего вечера 3 ноября

- Игра 36, #5 Millourt, citizen: правильные голоса +16, верная серия +2; ошибочные голоса −8 и −16, отрицательная серия −4; командное поражение −15. Сейчас −25 за игру. При новом пробном варианте: +16 +2 −6 −12 −15 = −15. Критическая ошибка раньше фактически стоила −20 с серией. Никакого изменения входных рейтингов других игр в этом сравнении нет.
- Игра 33: убитый #9 Диссонанс (sheriff) записал #7 Денди (citizen) чёрным. За последующий голос в него #1 Насону, #5 Кавасаки, #6 Богданчику, #8 Аннушке (все citizen) начислено по −8. Новый базовый вариант — −6; вариант смягчения — −3 без серии. Ответственность автора за эту конкретную ошибку остаётся −8 (иные его действия отдельно). Это не весь итог игры и не деление одного общего штрафа между участниками.
- Игра 32: девять голосующих, попилом ушли #1 Кавасаки (citizen), #9 Богданчик (mafia), #10 Аннушка (don). `no_scoring` не выставлен. Автоматика `unscoredVotings` срабатывает лишь на 8/6; `gameActionFacts` исключает день с несколькими выходами. В результате попил не принёс +4 за каждого чёрного и −2 за красного. У участвовавших citizen из этого протокола недостаёт +6 базовых Elo, без повторной оплаты уже засчитанных находок. Например, #6 Пристань: действия +8 → +14, итог игры +54 → +60 при неизменной командной части. У #5 Денди дополнительно меняется обычный ошибочный голос −4 → −3, поэтому общий прирост по пробному варианту +7.

## Что поправить после согласования

1. Цены ошибочных голосов citizen и взаимодействие с отрицательной серией.
2. Точное условие/размер смягчения по чужому завещанию и что делать с противоречивыми мнениями.
3. Попил на девятке/другом размере: учесть согласованный результат без дублирования голосов и кредита найденного чёрного.
4. Явная строка на итоговой картинке «За победу / За поражение», с фактической поправкой за состав; не всегда плоские +35/−15. Отдельно действия/личные бонусы/лимиты/фиксированные штрафы/дисциплина/весь итог.
