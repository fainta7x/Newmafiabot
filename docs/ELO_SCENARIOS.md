Штраф за ошибочный голос или цвет — часть оценки игровых действий. Он показан, несмотря на нулевую дисциплину: это разные компоненты. Если просьба владельца означает убрать также ошибки из оценки, требуется отдельное уточнение.

Сначала автоматические поправки суммируются, затем ограничиваются диапазоном **−35…+35 ЭЛО на игру**. Это ограничение не распространяется на судейские баллы, ЛХ или Ci.

| Прочие личные начисления | Поправка |
| --- | ---: |
| Балл судьи / протокольный бонус | Каждый +0,1 балла = +4 ЭЛО; отрицательные значения аналогично |
| ЛХ: угадано 0 чёрных | 0 |
| ЛХ: угадан 1 чёрный | +4 |
| ЛХ: угадано 2 чёрных | +12 |
| ЛХ: угадано 3 чёрных | +24 |
| Ci: допустимая компенсация первому убитому красному с квалифицирующим ЛХ | До +8 при победе красных; до +16 при их поражении |

Точные условия допуска ЛХ/Ci, нулевого круга, критического голосования и известных чёрных принадлежат BUSINESS_RULES; таблица не расширяет их. Автоматический вклад применяется к клубным играм; турниры сохраняют канонические личные очки.

## Отдельный бонус абсолютного уровня стола — запрос подтверждён, размер не выбран

Владелец подтвердил, что нужен бонус за сам факт игры среди сильных участников даже при равных командах. Это отдельная добавка **Bстола**, а не множитель подписанного командного результата: иначе «бонус» увеличивал бы потери при поражении.

**Предлагаемое разложение: итог = командный результат × личная нагрузка + личные очки + Bстола. Дисциплина в этих таблицах равна нулю.**

| Абсолютный уровень стола | Добавка к каждой строке выше |
| --- | ---: |
| Обычный | 0 |
| Сильный | +B₁ |
| Очень сильный | +B₂, где B₂ > B₁ > 0 |

B₁/B₂ и правило определения сильного стола ещё не согласованы. Не подставлять вымышленные значения в действующий расчёт. При использовании одной и той же шкалы сравнения бонус одинаков для обоих цветов и обоих исходов: он награждает уровень стола, тогда как сложность победы и личная нагрузка уже учтены своими блоками.

Пример исключительно для понимания: если отдельно выбрать Bстола = +4, сильный красный в равной команде получает +45,50 + 4 = +49,50 за победу или −9 + 4 = −5 за поражение; личные очки затем добавляются отдельно. Число +4 для бонуса стола **не утверждено и не внесено в код**.

## Дисциплина

Во всех числовых сценариях этого документа дисциплинарное вычитание равно **0**. Фразу владельца «За дисциплину не вычитал ничего» требуется уточнить: это условие примеров или исключение дисциплинарных штрафов из самого ЭЛО. До уточнения код дисциплины сохранён; этот документ не отменяет ранее действовавшие игровые штрафы.
