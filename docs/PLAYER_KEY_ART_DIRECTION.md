Use the existing owner-supplied player photos and art references for the selected player; do not assume all inputs are missing. Establish a recognisable master illustration and validate likeness, anatomy and composition before producing variants. Preserve the real broadcast/card base when a preview targets those surfaces. Keep prompts, references, revisions and approvals with the accepted asset. No new art generation, runtime wardrobe, inventory or portrait animation is implemented by this documentation PR.
