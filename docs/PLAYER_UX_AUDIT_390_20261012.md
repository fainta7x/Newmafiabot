## Ограничения и проверка перед слиянием

- Не менять API, правила игры, расчёты Elo, персональные данные, сохраняемые протоколы и баланс.
- Проверить реальные значения винрейта: 0 игр → «—», 3 игры и 2 победы → 67%, скрытая статистика другого игрока не должна появляться.
- На 360 / 390 / 430 px проверить, что диаграмма с числами не вызывает горизонтального скролла, переключение периода / формата обновляет значения, GoMafia и обучение доступны, «Подробная статистика» по-прежнему открыта, кнопки ≥44px.
- `Playwright` / GitHub Mobile preview подтверждают рендер, **не** успешную проверку боевого Telegram WebView. Просмотреть скриншоты перед merge и затем открыть профиль на телефоне.
