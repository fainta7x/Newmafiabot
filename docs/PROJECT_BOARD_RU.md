## В работе

- **«Что нового» для игроков.** Записи пишутся и публикуются из CRM («Ещё → Что нового»), игроки видят их на главной.
- **CRM: «Оплата и поддержка» и «Управление ставками».** Привести к виду остальных экранов: понятные слова, крупнее текст.
- **Возврат из «Музыкальной базы».** Из ведущего экрана музыки есть кнопка «Назад в CRM · Музыкальная база».
