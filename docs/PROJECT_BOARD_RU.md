# Проект 2LA Noire — короткая сводка для CRM

Это компактная русскоязычная витрина текущих задач на основе `docs/PROJECT_STATE.md`, а не новый источник задач. Исторические записи остаются в `PROJECT_STATE.md`; открытые PR обновляются из GitHub. При изменении статуса задачи обновлять и эту сводку.

## Нужен ваш ответ

- **Бот: подтвердить два ответа FAQ.** Уточнить «Можно прийти с другом?» и «Как оплатить?» перед правкой ответов игрокам.
- **Площадка: согласовать работу ночью.** Уточнить у кафе «Суп с Котом», что вечера могут идти до 02:00, при указанном графике работы до 22:00.
- **Проверить новый релиз на телефоне.** После деплоя открыть «Ещё → Проект», ответы игроков, свой профиль и рейтинг. Сообщить о конкретных ошибках со скриншотом.

## В работе

- **Удобство личного кабинета игрока.** Уменьшить текстовую перегрузку, проверить навигацию, понятность результатов и возвращение из игр на узких экранах.
- **CRM: один список ответов игроков.** Объединить отклики, личные сообщения и недоставленные анонсы, устранить ошибку перехода из «Сегодня».
- **Аудит сезонов и завершённых игр.** Свести дату завершения, выбор рейтингового периода и источники статистики без переписывания истории.
- **Покер: ненавязчивые звуки событий.** Раздача, фишки, собственный ход и окончание времени с отдельным выключателем.
- **GoMafia: проверка на реальных турнирах.** Код PR #852 слит в основную ветку. После деплоя проверить автосинхронизацию и данные игрока.

## Планируем

- **Кабинет: второй проход аудита.** Проверить кошелёк, покер, настройки и профиль на телефоне, исправлять только воспроизводимые проблемы.
- **Вечера новичков: автоматическое расписание.** Пока публикация остаётся ручной, автоматизация требует отдельного решения владельца.

- **Базовые переходы и быстрый выбор в CRM.** Переход к ответам и добавление участника сделаны в PR #841/#843; проблема перехода из «Сегодня» исправляется отдельно.
