# Виртуальная раздача ролей — решения владельца (28.10.2026)

## Утверждено

- Во всех игровых форматах доступна виртуальная перемешанная колода; существующая ручная фиксация физических ролей остаётся альтернативой.
- Колода содержит точное количество необходимых ролей по формату/числу игроков. Роли уже открытых карт не меняются. Сохраняется состав колоды.
- Карты в одном горизонтальном ряду с прокруткой на телефоне. После выбора карта убирается, оставшиеся сдвигаются и последовательно перенумеровываются.
- Порядок выбора по умолчанию — места 1–10; можно выбрать следующего игрока вручную.
- Ведущий открывает карту игрока, затем подтверждает её и переходит к следующему.
- Доступны отмена последнего выбора до старта и полная перераздача с подтверждением.
- Скрытые индивидуальные настройки вероятностей доступны **только владельцу**; ведущий их не видит. На рейтинговых и турнирных играх любые подмены запрещены сервером; разрешены только на обычных клубных и новичковых.
- Процент означает вероятность срабатывания конкретного правила при выполнении его условий, а не заданную итоговую частоту роли.
- На одного игрока можно задать несколько правил. Лимит — общий за вечер (по умолчанию 2 успешные подмены) и отдельно на игрока (значение ещё не утверждено). Неуспешные попытки лимит не расходуют.

## Новые механики — на совместное обсуждение

1. «Подменить свою роль» — условная замена полученной карты на роль из неоткрытой колоды.
2. «Получить желаемую роль» — при доступности цели обменять карту с ещё закрытой.
3. «Одноцвет с игроком X» — попытка обеспечить командам совпадающий цвет, в том числе когда карту первым тянет X.
4. «Не одноцвет с игроком X» — попытка обеспечить противоположные команды.

Для правил 3–4 пока **нет утверждённой реализации**: надо согласовать, допускается ли корректировка только на момент открытия карты второго игрока, что делать если один/оба уже получили карту, как обрабатывать конфликт нескольких правил/приоритет, и допустимо ли резервирование скрытой карты без изменения роли после открытия. Не менять раскрывшиеся роли молча.

## Инварианты и проверки

- Только сервер принимает решения о подмене/правах, а не браузер ведущего.
- Ни один рандомизированный выбор не приводит к дублированию/потере роли.
- Лимиты применяются атомарно к вечеру и игроку; повторное подтверждение/повтор запроса не запускает новую попытку.
- Обычная честная раздача остаётся доступна без скрытых правил, а режим подкруток не используется для рейтинга/турниров.
- Не выдавать предварительные проекты механик как согласованные правила.

## Открытые решения

- Число успешных подмен **на одного игрока** по умолчанию.
- Приоритет между несколькими совпавшими правилами и влияние на вероятность.
- Точное значение «одноцвета» для красных ролей (мирный и шериф — один цвет?) и чёрных (мафия и дон — один цвет?).
- Можно ли связывать правило с игроком, который уже открыл свою карту, или только со следующим неоткрытым.
- Политика публичного раскрытия факта управляемой раздачи участникам клуба (без публикации персональных настроек).
