# Найти игру и понять результат — 27 октября 2026

Продолжение согласованного постраничного разбора после #1059. Исходная база53c18c9 (код совпадает с проверенным кандидатом8358550). Разобраны связанные задачи из P11/P13/P32/P34; это продолжение исследования удобства, а не повторный глобальный поиск ошибок.

| ID | Почему мешало | Что реализовано |

Раскрывается именно сохранённый расчёт; переход открывает соответствующий протокол. |
| H02 | В общем архиве длинный список без поиска; подпись обещала «полный» архив, хотя API отдаёт ограниченную выборку. Возврат из игры терял раскрытие списка. | Поиск по названию, номеру, судье и дате среди загруженных записей; видны число совпадений, отсутствие совпадений и сброс. Раскрытие и запрос сохраняются при возврате из игры в том же представлении. |

Для старого ответа без номера — «Открыть игру»; номер не выдумывается. Отсутствие участия показывается только когда источник явно это подтвердил. |
