# Итоги, протокол, повтор и сезон: следующий разбор страниц

Дата: 27.10.2026. База: main de7e99f (#1063). Задача владельца: продолжать анализ следующих страниц параллельно проверкам уже подготовленного блока.

Это разбор реальных подключений компонентов, состояний интерфейса и серверных ответов. В этом проходе не запускались игровые тесты, не проводился новый осмотр телефона и не использовались production-данные. Никакие правила начисления или записи игр не менялись. Ранее полученные мобильные снимки не выдаются за новую проверку этих находок.

## Страницы по порядку

| Страница / режим | Что уже разумно | Что требует внимания |
| --- | --- | --- |
| Вечера → Прошедшие → итог вечера | Один итог объединяет счёт, личные результаты и фактические номера игр. Исправления #1060 присутствуют. | Переход в игру сохраняет исходный вечер, но подпись возврата в самой игре этому не соответствует: F01. |
| Мои игры / общий архив → отдельная игра | Личная история стоит первой, общий архив отдельно, поиск среди загруженных записей обозначен честно. | При сбое отдельной игры нет повторной загрузки: F02. |
| Итог игры / мой результат | Командный итог, личная роль, баллы и Elo различаются. Подробная статистика не заполняет экран по умолчанию. | Перестройка состава или дополнительный рейтинг не нужны. F01/F02 относятся к действиям вокруг результата. |
| Подробный протокол | Состав, заявления и фактические события имеют отдельные владельцы; раскрытие сохраняет компактный итог. | После перехода в Replay этот компонент создаётся заново и раскрытые разделы закрываются: F04. |
| Replay: кадры OBS / восстановление по событиям / старая хронология | Показывается источник записи и ограничение старого протокола; переходы по моментам из #1059 уже есть. | Временный сбой нельзя повторить с этого экрана: F03. |
| Replay → записи речей | Отсутствие записей отделено от ошибки их загрузки, есть группировка по кругам. | Нет повтора загрузки речей (F03); обещание прослушать всё подряд не соответствует отдельным плеерам (F05). |
| Replay → авторазбор | Текст основан на сохранённых фактах, без мотивационных догадок. | При отсутствии распознанных фактов текст «Переломных моментов… не нашли» делает слишком сильный вывод: F07. |
| Сообщество → Рейтинг → Сезон → начисления игрока | Состав баллов виден; загрузка таблицы и списка периодов уже имеет повтор. | Переход к протоколу предусмотрен компонентом, но не подключён в приложении: F06. |
| Сообщество → Активность → Матчи → карточка матча | Есть краткий результат и повтор после сбоя; это полезный обзор события. | Нет прямого пути к полному каноническому протоколу: F08. |

## Конкретные исправления и примеры

| Код | Что сейчас происходит | Предлагаемое поведение | Приоритет |
| --- | --- | --- | --- |
| F01 | Из итогов вечера открывается игра. Кнопка пишет «К играм», но фактический Back возвращает к итогам этого вечера. | Называть действие «Назад» либо показывать реальное место возврата. Сохранить существующий корректный маршрут. | Ближайший блок |
| F02 | Сеть кратко пропала при открытии игры. На экране остаются ошибка и «К играм»; загрузить эту же игру повторно нельзя. | Кнопка «Повторить» повторяет только GET выбранной игры. Номер игры и исходный маршрут сохраняются. | Ближайший блок |
| F03 | Повтор партии не загрузился — доступен только Back. Если не загрузились только речи, есть лишь сообщение об ошибке. | Независимый повтор для Replay и для речей. Повтор речей сохраняет позицию повтора партии и не перезагружает результат игры. | Ближайший блок |
| F04 | Игрок раскрыл подробный протокол, открыл Replay и вернулся. App временно заменял весь кабинет, поэтому раскрытия протокола потерялись. | При возврате в ту же игру восстановить раскрытые разделы. Позицию страницы проверить отдельным коротким браузерным сценарием: этот анализ не доказывает поведение прокрутки. | Следом за восстановлением загрузки |
| F05 | Над независимыми аудиоплеерами написано «Слушай всю игру подряд». Перехода к следующей записи по окончании нет. | Точно описать существующую возможность: выбрать запись или круг. Автоматический плейлист — отдельная необязательная функция, сейчас не нужен. | Ближайший блок, правка текста |
| F06 | В начислениях сезона отсутствует кнопка протокола, потому что PlayerRatingHub не передаёт onOpenGame в PlayerRatingPeriods. | Подключить существующий переход. Перед ним сохранять выбранные период и игрока, чтобы Back возвращал к тем же начислениям. Потеря этого контекста после такого перехода — требование к будущей реализации, а не уже проверенный пользовательский сценарий. | Ближайший блок навигации |
| F07 | Старая запись не дала распознанных фактов для разбора. Сервер пишет, что переломных моментов не нашли. Это можно понять как оценку самой партии. | Сообщать об ограничении записи: «В протоколе недостаточно данных для подробного разбора». Не придумывать отсутствующие события. | Ближайший блок, правка текста |
| F08 | Из карточки матча в Активности нельзя одним действием открыть её полный протокол, хотя gameKey уже известен. | Один явный переход в существующий протокол. Карточку оставить кратким обзором. При Back сохранять исходную карточку/вечер. | После основного пути |
