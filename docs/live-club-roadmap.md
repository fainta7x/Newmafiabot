# 2LA Noire · «Живой клуб» roadmap

Цель: превратить приложение из CRM/кабинета в живой цифровой мир клуба, который интересно открывать даже вне записи на вечер.

## Roadmap

- [x] 1. Live-центр клуба — активный вечер, счёт, текущая десятка, ведущий, последние результаты, автообновление.
- [x] 2. Форма игрока — последние 10 игр, серии, победы/поражения.
- [x] 3. «Кто сейчас в огне» — автоматические серии и яркие достижения текущей формы.
- [x] 4. Weekly Power Ranking — развлекательный рейтинг формы, отдельно от официального Elo.
- [x] 5. Личные противостояния (Rivalry).
- [x] 6. Лучшие связки игроков.
- [x] 7. Карьера по ролям: Мирный / Шериф / Мафия / Дон.
- [x] 8. Карточка матча / MVP игры.
- [x] 9. История вечера как событийная лента.
- [x] 10. Итоговое табло вечера.
- [x] 11. Игрок вечера: автоматический + симпатия игроков.
- [x] 12. Голосования после вечера.
- [ ] 13. Персональные челленджи.
- [ ] 14. Выбираемые титулы рядом с ником.
- [ ] 15. Коллекционные карточки игроков / share PNG.
- [ ] 16. Сезоны клуба.
- [ ] 17. Зал славы и рекорды клуба.
- [ ] 18. Автоматическая новостная лента клуба.
- [ ] 19. Умные персональные уведомления.
- [ ] 20. «Разведка стола» перед игрой.
- [ ] 21. Elo «что если?» до игры + объяснение изменения после.
- [ ] 22. График карьеры Elo с событиями.
- [ ] 23. Персональная игровая аналитика.
- [ ] 24. Заклятые соперники / удобные оппоненты.
- [ ] 25. Социальный граф клуба.
- [ ] 26. Интерактивный Replay партии.
- [ ] 27. Разбор партии поверх Replay.
- [ ] 28. Режим большого экрана `/live`.
- [ ] 29. Итоговый экран завершения вечера.
- [ ] 30. Профиль игрока как полноценная игровая карьера.

## Принципы реализации

1. Маленькие законченные итерации, без гигантских рефакторингов.
2. Существующие игры, протоколы, Elo, профили и турниры — источник истины; не плодить параллельные модели.
3. Скрытые роли и закрытая игровая информация никогда не попадают в spectator/live-интерфейс до завершения партии.
4. Новые механики вовлечения не должны менять спортивный результат игры и официальный Elo без отдельного решения.
5. Полный CI запускается пакетно после законченного крупного блока, а не после каждой небольшой правки.
