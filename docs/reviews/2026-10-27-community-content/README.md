| --- | --- |
| CT01–CT03 | Обзор различает результат среза и текущее положение. Аналитика подписывает свой период, показывает победы/игры и сравнивает с предыдущими десятью только при полном наборе двадцати. Сервер отдаёт факты вместо оценки силы по винрейту. |
| CT04 | Роли: победы из числа игр и до пяти сохранённых исходов от старого к новому. Неизвестные исходы не дорисовываются; средние баллы со смешанным источником не добавлены. |
| CT05–CT06 | Решения сгруппированы по контексту, покрытие журналами/знаменатели/исключения сохранены. Ночь описывает командные события, вскрытия — объявленные проверки, уходы — обстоятельства. |
| CT07–CT08 | Контекст метрики и порядок рядом с таблицей; методика под списком. GoMafia явно имеет собственный охват. Ролевая таблица объясняет порядок по числу игр и показывает победы/игры. |
| CT09–CT10 | Форма подписывает последние десять и интервал движения места. Сезоны/архив: доступные даты и основание ранжирования. Рейтинговый период: даты, баллы, дистанция. Турниры: промежуточность/окончательность результата. |
| CT11 | Карьера различает судейский и протокольный доп. В Elo перед полным расчётом показаны сохранённые командная/личная части; формулы и значения не изменены. Протоколы Claude #1071 сохранены. |
| CT12–CT13 | Внешняя карьера подписывает источник; управление привязкой после результатов, сворачивается при наличии сводки. Работа в клубе имеет отдельный заголовок. Команда явно отличается от игр против. Корректные клубные истории сохранены. |
| CT14–CT15 | Цели выбранного пути предшествуют полученному и закреплённому; остаток только при известном счётчике. Обучение начинает с задачи и существующего направления, затем предлагает практику. |

## Проверки и границы

Только затронутые компонентные/агрегаторные проверки. Первые39 кейсов:37 успешных и два ожидания прежних подписей; ожидания обновлены с сохранением проверки значений/срезов. Затем27/27 в пяти затронутых файлах. После уплотнения сводки/метрики —35/35 в пяти файлах, включая настоящую интеграцию metricRating и три Hero cases. Ранее прошедшие12 кейсов не повторялись без изменения их владельца. Обновлённая проверка порядка исходов отдельно различает прямую и обратную последовательность.

`community-content-preview.spec.mjs` подключён к обычному UI preview:20 состояний ×360×640,390×844,1366×768,1440×900 =80 чистых аудитов неизменённым `auditScreen`; четыре browser cases проходят. Раскрытые наблюдения/Elo/методика, решения/ночь/вскрытия/уходы, роли, цели, команда, метрики/федерация/ролевая таблица, форма, сезон/архив, обучение, GoMafia. Четыре состояния «до» и четыре сопоставимых «после» при390×844 отдельно прошли тот же аудит. Все восемь снимков прочитаны; итоговые сводка/роли/метрики повторно просмотрены после найденного при первом просмотре избытка текста. Поэтому методика под списком, а исходы компактны и имеют доступные подписи.

TypeScript, lint затронутых владельцев, release safety audit и dependency guard проверены локально. Финальный CI опубликованного SHA обязателен; локальные проверки не доказывают слияние или production. #1071 включён ребейзом; он не меняет стили/владельцев этих экранов, поэтому картинки сохраняют соответствие. Его протоколы не перезаписывались.

Все картинки — изолированные синтетические данные. Перед/после используют одинаковые основные значения; богатый сценарий `?content=1` дополнительно проверяет существующие серверные поля. Отсутствующее поле стенда не трактуется как отсутствие данных production. Новые агрегации для советов по ошибкам, общая шкала average_score, личный итог каталога турниров и коэффициент совместимости прямо исключены из согласованного плана. Условия наград, приватность, отсечки и формулы не изменены. Подробная статистика остаётся открытой.

Без production writes, реальных сообщений, Amvera synchronization и проверки живого развёртывания.
