## Воспроизводимость

Собрать `node scripts/buildUiPreview.mjs`; использовать страницы `e2e/player-cabinet.html?booking=rating&route=/player/events/preview-evening`, `?route=/player/wallet`, `?route=/player/rating`, `?route=/player/settings`, `e2e/protocol-window.html`, `e2e/split-vote.html?tab=home`, `e2e/split-vote.html`, `e2e/crm-closeout.html`. Для ошибки отмены добавить `saveFailures=1`. Для настоящего App использовать `root=1` в player-cabinet harness. Фикстуры сбрасываются при перезагрузке, внешние запросы не нужны.

Автоматизированные регрессии отмены и расчёта цены находятся в `src/tests/bookingCancellationUX.test.tsx`, `PlayerBookingUsability.test.tsx`, `PublicJoinConfirm.test.tsx`; существующий `e2e/tests/current-booking-preview.spec.mjs` учитывает отдельное подтверждение отмены. Обязательный CI проверяет точный SHA PR; локальные изображения сами по себе не доказывают успешное слияние или деплой.
