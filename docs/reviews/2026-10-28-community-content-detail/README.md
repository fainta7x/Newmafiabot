- **Решения:** общий объём действий и визуальное распределение красные/чёрные/неизвестно. Шериф указан внутри красных, не прибавляется второй раз. Отсутствующее поле не становится0. Исходные проценты точности и их исключения не меняются.
- **Свои связи:** три уже передаваемые последние общие партии с датой, названием и контекстом. Результат совместной игры показан только при известном флаге; игра против не выдаётся за поражение. Известные совместные победы доступны и при одной-двух играх в команде. Старому ответу без результата не приписывается0.
- **Охват:** существующие минимальный объём/предел списка передаются из владельца как метаданные. Правила2/24, порядок и выбор «результативного напарника» не меняются. Его карточка теперь описывает победы без универсального утверждения о силе. История партий добавлена только в собственный профиль; публичный не расширяет раскрытие.
- **Цели:** контекст партии/вечера/турнира/карьеры/подтверждённых приглашений рядом с исходным условием. Счёт относится к выбранному пути; полный путь имеет явное подтверждение. У «Четырёх лиц» объяснено, что отмечены роли с победой. Награды и их условия/алгоритмы сохранены.
