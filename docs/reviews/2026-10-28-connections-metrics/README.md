# Связи и Показатели: согласованный контент

Полный [анализ CN01–CN08](../../UX_CONNECTIONS_METRICS_CONTENT_REVIEW_2026-10-28.md) завершён до правок и утверждён владельцем («Да, продолжай»). Одна связанная реализация; новых решений от владельца не требуется.

Новые пороги/порядок/границы описаны в BUSINESS_RULES. Дополнительные настройки раскрываются, содержание видно раньше. Новая связка не повторяется в прежнем списке пар с одной игрой. |

## Проверки и ограничения

Целевые unit/API/component проверки проходят: прежняя metric integration расширена реальными SQLite кейсами для матрицы, полного списка, приватности, ролей, null и фильтра истории пары; отдельные четыре случая проверяют серии/период/namespace/роль/скрытые связи. Компонентные проверки — таблица/поиск/сортировка/любая пара/переход/GoMafia/ошибка/сохранение фильтров. TypeScript, changed-source ESLint и dependency guard проходят. Обязательный exact-head CI отдельно от локальных проверок.

Семь browser flows проходят: новый маршрут на360×640,390×844,1366×768,1440×900; три затронутых старых сценария на390px. В новом маршруте19 состояний ×4 =76 чистых auditScreen-проверок; baseline captures также audited. Detector/thresholds/exceptions не менялись. После просмотра первоначальных снимков уплотнены панели настроек: таблица начинается на первом экране. Повторён только затронутый проход, затем окончательный четырёхразмерный маршрут.

Все шесть изображений просмотрены; это реальные screenshot браузерного harness с appStyles, синтетические данные, не runtime клуба. Основной пример сохранён: Александра —8 побед в12 играх; новый второй игрок нужен для показа сравнения. Две дополнительные картинки показывают новые состояния, у которых не было прежнего аналога.

Не меняются Elo, спортивные баллы, допы, дисциплина, Формa, правила игр, старые пороги и приватность. Промах команды не становится личной ошибкой; факт ночного выбытия при чёрной роли другого не доказывает автора выстрела. Текущая серия относится к общим играм выбранной пары, а не ко всем играм обоих игроков. First-recorded не означает, что известны незаписанные игры. Слияние, деплой и runtime verification — разные состояния. Production writes/messages/Amvera sync не выполнялись.

UI2269: общий аудит всех страниц прошёл. Шесть старых preview-случаев в двух owners ожидали две кнопки вместо двух профилей плюс истории и дублированную первую пару. Исправлены только тестовые ожидания: проверяется единственная новая пара, две профильные кнопки, отдельный переход в историю, прежний бюджет плотности тела карточки180px и тач/viewport guards. Все шесть целевых случаев проходят за1,3мин; приложение/detector не менялись. Основной CI и безопасность прошли; повторный exact-head CI/merge относятся к поправке тестов.
