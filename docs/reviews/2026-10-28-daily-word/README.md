## Dictionary

Curated everyday answer pool; broader accepted noun list filtered to Cyrillic4–8 letters and normalized ё→е from https://github.com/Harrix/Russian-Nouns/blob/main/dist/russian_nouns.txt (retrieved2026-10-28). MIT copyright/license retained verbatim in `src/server/data/russian-nouns-LICENSE.md`. Lists are bundled server-only; no daily external/AI dependency.

## Limits

Isolated synthetic fixtures and in-memory DB, not signed-in production/runtime verification. Rates of return and engagement are hypotheses to measure after release; no retention improvement is claimed. New puzzle/session tables initialize additively; existing balances/history/game rules are preserved. Profile merges use the existing canonical player-column discovery; overlapping daily sessions correctly remain a merge conflict rather than silently awarding another prize.
