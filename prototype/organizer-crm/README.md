# Interactive Organizer CRM Prototype

Standalone mobile-first UX sandbox for approving organizer workflows before they are implemented in the production CRM.

It deliberately uses in-browser test data only. Nothing in this directory calls the real API, changes player records, sends Telegram messages, or opens a live game.

Primary interaction flow:

`Анонс → Ответы → На месте → Игры`

The GitHub Pages workflow publishes this directory separately from the production Amvera deployment.
